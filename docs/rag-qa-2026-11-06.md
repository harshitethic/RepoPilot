# RAG QA: November 6, 2026

This report documents **observed test results** for RepoPilot's local BM25
retrieval feature. It distinguishes tests of a real model from stubs.

## Automated regression

Run from the repository root after installing `backend/requirements-test.txt`:

~~~bash
PYTHONPATH=backend python -m unittest discover -s backend/tests -v
~~~

Observed on the maintainer's local macOS checkout:

- **180 tests run; 179 passed, 1 skipped, 0 failures** (11.6 seconds).
- Added relevance regressions verifying nonexistent snake_case symbols do
  not accidentally match an individual component such as "never".
- Added real multipart ZIP import / RAG lookup / repository-deletion
  tests across two isolated repositories.

This is a dated local test result, not a continuous uptime or quality claim.
GitHub CI results should be checked separately for the committed revision.

## Live HTTP integration

Run `python examples/rag_live_http_smoke.py` to start a disposable localhost
Uvicorn server, import actual RAG source files in a ZIP, and test 23 assertions.

Observed: **23/23 passed** after the relevance correction.

- All five code-location queries retrieved the expected source as rank **#1**.
- File paths and source-line citations were present in each returned hit.
- Nonsense identifiers returned no fabricated retrieval evidence.
- Invalid path prefixes, unknown repository IDs, and untrusted CORS origins
  were rejected.
- The no-evidence case did not query the model.
- A **stub** local Ollama HTTP service confirmed prompt forwarding and response
  serialization; it was not an actual LLM inference.
- Deletion removed the imported repository and subsequent retrieval returned
  HTTP 404.

## Real GitHub import

A separate local ASGI request imported the **public RepoPilot GitHub
repository** through the real `/api/analyze` route.

- Import completed with HTTP 200 and 102 indexed source files in the
  checked-out revision (about 1.85 seconds on this machine).
- The subsequent RAG query successfully cited `backend/services/rag/chunk.py`.
- A request requiring a model returned HTTP **503**, with the safe public
  message "Local AI service is unavailable", because no Ollama service
  was running on the test Mac.
- The imported copy was removed through the API; no imported repository
  directories remained in the temporary store.

## Retrieval timing (not a production benchmark)

- Repeated small backend-tree retrievals: about **0.03–0.11 seconds**.
- Synthetic 350-file / 150-line-per-file corpus: about **0.90 seconds**.
- These are single-machine observations without simultaneous requests,
  varied storage conditions, or a persistent production load test.

## Remaining limits

- The generated *content* quality of a real Ollama model was **not tested**.
- BM25 is lexical; queries that only use synonyms can miss relevant files.
- Tests and references may sometimes rank above the definition itself.
- This is a local-only trusted-workstation service, not an internet-facing,
  audited multi-tenant RAG platform.
- The tests do not establish defenses against every possible prompt injection
  or repository abuse.
